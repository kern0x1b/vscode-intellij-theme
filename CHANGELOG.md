- Updated tree indent guide stroke colors

### Added

### Added
- IntelliJ IDEA Islands Dark theme
- IntelliJ IDEA Islands Light theme
- Semantic highlighting support
- Syntax highlighting for Java, Kotlin, TypeScript, JavaScript, Python, Go, Rust, C/C++, C#, and more
- Consistent UI styling for all VS Code elements
- Extension icon
